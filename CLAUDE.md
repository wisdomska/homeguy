# Design skills

This repo vendors the taste-skill pack (`npx skills add Leonxlnx/taste-skill`) in `.claude/skills/`,
pinned by `skills-lock.json`. For any UI or UX work, load and follow the matching skill before
designing: `redesign-existing-projects` when improving existing screens, `design-taste-frontend`
for new pages, and `high-end-visual-design` for visual polish. Update the pack with
`npx skills update`.
